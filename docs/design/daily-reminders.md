# 2日に1回、20時の投稿リマインダー

## ユーザー向けの動作

- 通知のアプリ設定は初期値オン。自分でオフにした保存済み設定は保持する。独自の初回案内は表示しない。
- 初回投稿・オンボーディング終了後、ホームの更新通知やガイドが終わったら、未確認の場合のみiPhone標準の通知許可画面を表示する。すでに許可／拒否している場合は再表示しない。
- 設定 → 通知 → 投稿リマインダーでオン／オフを変更できる。時刻の変更機能は設けない。
- 通知を有効にした日を基準に、2日後の20時から2日に1回、端末の現地時間20時に1通。基準日は保存し、アプリを開いても先延ばししない。オフから再びオンにした場合は基準日を更新する。
- 予定日に投稿済みなら、その回を取り消し、次の予定日まで通知しない。翌日への振り替えはしない。
- 投稿の引用が予定されている日は引用通知を優先し、20時の投稿リマインダーは送らない。引用を開いた後や、届いた引用を非表示にした後も、その日はリマインダーを再予約しない。引用が届く前に非表示にした場合は通常のリマインダー予定に戻す。
- アプリを利用中に届いたリマインダーはバナーも音も出さない。
- 通知をタップすると投稿画面を開く。終了中からの起動にも対応。
- 常連がいる場合は「UPME!｜常連の表示名」を通知タイトルにし、保持しているキャラクターに合った本文を使う。2人以上なら前の通知と同じ常連を避ける。
- 1キャラクター10文を使い切るまで同じ文を繰り返さない。常連がいない場合はUPME名義の汎用文。
- アプリで選択中の日本語／英語に従う。名前・言語・常連の追加や解除後は予約を更新する。
- 利用しない期間が長くなっても頻度を減らさない。

## 実装と制約

`DailyReminder.swift` がiPhone内でローカル通知を予約する。APNs、Render、DBの変更や日々のAI API呼び出しは不要。

変化する文言と「当日投稿済みなら送らない」を両立するため、繰り返し通知ではなく、先60回分を個別に予約する。起動・アクティブ復帰・投稿・設定変更・時刻変更の際に予約を更新する。他用途の保留通知がある場合は空き枠を優先する。

**約120日間まったく起動しない場合、60回の予約を使い切ると通知は止まる。** 頻度を下げるルールによる停止ではなく、端末内予約の有限性による制約。無期限の通知と継続的な文言変更の両立には、別途APNs等からのサーバー配信が必要。

通知の表示はiOSの通知許可・集中モード・通知要約等に従うため、20時の画面表示を保証するものではない。端末のタイムゾーンに固定せず年月日と20時を予約し、時刻変更時と復帰時に再計算する。

通知用のキャラクターIDがない古い常連は、バックエンドと同じSHA-256による安定した割り当てを使用。通常の返信・記憶の生成方式は変更しない。

`DailyReminderCopy.json` は日本語／英語の文案Markdownから生成した600文。通知本文や常連名・会話内容は計測に送らない。

## 計測

- `daily_reminder_preference_changed`: 通知のオン／オフ結果。
- `daily_reminder_scheduled`: OSへの予約成功数。配信数や閲覧数ではない。
- `daily_reminder_opened`: 通知のタップ。キャラクターID、文言番号、言語、予定日。
- `daily_reminder_post_created`: 通知を開いてから1時間以内の最初の投稿。投稿フローIDと経過秒。通知が投稿を引き起こしたと断定する指標ではない。

## 確認

`scripts/check_daily_reminders.swift` で600文・2日に1回の20時・投稿済み日と引用予定日の除外・常連と文言のローテーション・再起動時の選択と予定日の安定性・日英・夏時間を確認する。実機での通知許可、実際の通知表示、タップ遷移は別途確認する。

デバッグビルドのみ、設定 → 開発用 → テスト通知を送る、から10秒後の通知を予約できる。常連と言語に応じた本文を使い、アプリ利用中にもバナーを出す。タップすると投稿画面を開く。通常のリマインダーがオフ・投稿済みの日でも試せるが、iOSの通知許可は必要。通常の予定日や文言履歴は変更せず、テスト通知のタップは継続率分析用のイベントに含めない。リリースビルドにボタン・テスト予約機能は含まれない。

Apple公式資料: [ローカル通知の予約](https://developer.apple.com/documentation/usernotifications/scheduling-a-notification-locally-from-your-app)、[通知デリゲート](https://developer.apple.com/documentation/usernotifications/unusernotificationcenterdelegate)。
