# UPME default avatar

Selected concept: D, the off-white companion with a pink heart tuft.
Asset: `Assets.xcassets/UPMEMascot.imageset/upme-mascot-heart.png`.
Generated using the built-in image generation tool, not the CLI/API fallback.

The asset is bundled locally and needs no image-download request. It is used only when
the user has not chosen a valid custom photo. Existing user photos and persisted data
are not replaced. Profile, post composer, feed posts, onboarding, and user replies all
use this default. The app launcher icon and AI follower avatars are unchanged.

## Final prompt

Use case: precise-object-edit. Input image is edit target: four-panel UPME mascot board.
Extract ONLY mascot D in bottom right and create its final square profile avatar.
Preserve D identity precisely: off-white rounded friendly ghost-like little companion,
two dark dot eyes, tiny curved smile, two rounded feet, a small curved extension to its
right, and pink heart tuft above the upper right of its head. White body stays white,
do not recolor body pink. Heart uses app hot pink #EC4899. One large centered mascot
on uniform dark charcoal #211E29 square background. Subject including heart fits well
inside a circular crop with generous clear margin; occupies about 70% canvas width.
Simple clean flat 2D, no detailed texture or lighting effects. Remove panel layout,
all labels, other characters, circular border and tiny repeated thumbnail. No letters,
no text, no props. Production ready avatar.
