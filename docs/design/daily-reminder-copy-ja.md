# 常連からの投稿リマインダー文案（日本語・300本）

既存の30キャラクターに各10本。通知タイトルは「UPME!｜常連の表示名」、本文には以下の文を使います。2日に1回、20時の案内用です。英語版と合わせてDailyReminderCopy.jsonへ組み込んでいます。

投稿内容を知らなくても送れる呼びかけです。届いていない返信、知らない出来事や感情、過去の交流を装わず、投稿しないことへの罪悪感を与えない文言にしています。キャラクター名は管理用ラベルで、通知には表示しません。
