# UPME：最近の離脱・再訪傾向

分析日：2026-11-17 JST。PostHog project 565898の実イベントを読み取り専用で集計。観測は日本時間11月16日終了まで。定義は今回の分析用で、承認済みカタログ指標は登録されていない。

## 結果

新規利用者の多くは初日に通常投稿へ進むが、翌日以降の再訪が少ない。初日に複数回投稿した人でも再訪は限定的。「全員が1投稿で飽きた」とは解釈できない。

### 新規利用者の再訪

| 指標 | 直近 | 比較期間 |
|---|---|---|
| D1：翌日にdaily_active | 11/3〜11/15開始：23/118人（19.5%） | 10/20〜11/2開始：32/113人（28.3%） |
| D7：7日後ちょうどにdaily_active | 11/3〜11/9開始：1/60人（1.7%） | 10/20〜11/2開始：3/113人（2.7%） |
| 翌日〜7日目のいずれかに再訪 | 11/3〜11/9開始：15/60人（25.0%） | 10/20〜11/2開始：39/113人（34.5%） |

直近のD1は8.8ポイント低い。ただし標本は少なく、統計的な悪化やアップデートによる因果効果を確定したものではない。D7は11/10以降開始を除外。D1は11/16開始を除外。観測不足の日をゼロとして扱っていない。

11/3〜11/9開始60人では、初日オンボーディング完了51人（85%）、初日の通常投稿45人（75%）。これらは同日行動の独立集計で、厳密な順序付きファネルではない。
翌日〜7日目に再訪記録がない人は45/60人（75%）。これはその期間にdaily_activeがないという意味で、アンインストールや永久離脱を確認したものではない。

### 初日の通常投稿数との関連

対象は7日間を観測できる11/3〜11/9開始60人。通常投稿にはオンボーディングの練習投稿を含めない。

| 初日の通常投稿数 | 人数 | 翌日再訪 | 翌日〜7日目に一度でも再訪 |
|---|---:|---:|---:|
| 0回 | 15 | 1（6.7%） | 1（6.7%） |
| 1回 | 15 | 2（13.3%） | 3（20.0%） |
| 2回 | 7 | 1（14.3%） | 2（28.6%） |
| 3回以上 | 23 | 8（34.8%） | 9（39.1%） |

初日に3回以上使った人ほど戻る割合は高い。ただし元から関心が高い人が投稿も再訪もしている可能性があり、3投稿させれば継続率が上がると断定はできない。3回以上投稿した人でも翌日再訪は8/23人であり、初日の投稿回数だけでは解決しない。

### AI返信の受信・閲覧

1.1.2の投稿IDで突合できる通常投稿302件（実記録は11/14〜11/16）では、受信301件、閲覧300件、受信なし1件。受信時点の待ち時間は中央値4.387秒・90%点5.982秒・95%点6.842秒。未受信の1件はnetwork失敗イベントあり。

この待ち時間はAPI受信までであり、全返信の順次表示完了までではない。最新版の対象投稿に限られ、全ユーザーや旧版の品質へ一般化しない。

11/3〜11/16全体ではai_replies_failed 35件・15人、理由は全てnetwork。旧版にはpost_flow_idがなく、個々の投稿の最終成功・失敗を追えない。35件は未回復の35投稿を意味しない。

重要：ai_replies_viewedは1.1.2で11/13から記録開始。旧版を含めた「投稿→閲覧」の全期間ファネルは計測未導入を離脱と誤認するため、結論には使わない。参考として実行したネイティブファネル・リテンションはプロジェクト設定のUTCであり、本レポートの日本時間集計と混ぜていない。

## 解釈と優先順位

1. 主な課題は初日の体験後に戻る理由。初日通常投稿75%に対し、翌日以降7日内の再訪25%。
2. 今開発中の常連カードは「前の会話から何が変わったか」「続けると関係がどう深まるか」を伝える仮説として合う。ただし、本分析は未リリース機能の改善効果を示していない。
3. 初日に通常投稿しなかった15人の内訳も改善対象。投稿済みと比べ再訪が少ないが、主要課題を全てオンボーディングへ帰す根拠はない。
4. network失敗は継続監視が必要だが、最新版で受信301/302件という観測から、返信不達だけを再訪の少なさの主因とはみなしにくい。
5. 返信が肯定的か、似た内容で飽きたか等は本文を計測していないため不明。ユーザー調査等と組み合わせて検証する。

## 定義と限界

- 新規コホート：対象期間内でApplication Installedが記録されたPostHog person_id。人の実人数やApp Storeのダウンロード数ではなく、再インストール等の影響があり得る。
- 日付はAsia/Tokyo。再訪はdaily_active、D1/D7はそれぞれ翌日・7日後の暦日ちょうど。1〜7日内再訪は別指標。
- daily_activeは端末のローカル日付で一日一回記録されるため、海外利用や日付変更付近の挙動には限界がある。
- PostHog設定済みテスト除外に加え、$is_sideloaded／$is_emulator／$is_testflight=trueのイベントを除外。対象期間のApplication Installed127件は全て各フラグfalse。通常投稿はtrueの12件・1人を除外した。
- この分析で確認できるのはイベント上の不再訪。永久離脱率、離脱の心理的原因、アンインストール率ではない。
- 集計日当日の11/17は途中のため除外。個人ID・投稿本文・AI返信本文はレポートへ出力していない。
